# AI Terminal Chatbot

This project is a simple AI chatbot that runs in the terminal using Python and the OpenAI API.  
It allows users to have interactive conversations with an AI model directly from the command line.

## Features
- Interactive terminal chat
- Maintains conversation history
- Simple and beginner-friendly code
- Built using Python and OpenAI API

## Technologies Used
- Python
- OpenAI API

## How to Run

1. Install required library
pip install openai

2. Add your API key as an environment variable

3. Run the program
python chatbot.py

## Usage
Type your message in the terminal and the AI will respond.  
Type **exit** or **quit** to end the chat session.
